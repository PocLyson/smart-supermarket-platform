## 基础数据与账号

- [ ] 不少于 30 个真实商品已核对名称、售价、单位、图片、上下架状态及对应线上库存。
- [ ] 已创建且仅有一个老板账号，并至少创建一个收银员账号。
- [ ] 不少于 5 位顾客完成真实微信登录，未泄露 `session_key`。

## 订单闭环与对账

- [ ] 不少于 10 笔真实或试运营订单完成“下单—接单—备货—收款—完成”闭环。
- [ ] 抽查订单金额等于服务端商品快照小计之和。
- [ ] 订单状态、付款状态、状态历史和库存流水逐笔对账一致。
- [ ] 现金与微信扫码付款方式均完成至少一次记录验证。
- [ ] 同一幂等键重复提交未重复建单或扣库存。

## 权限与异常场景

- [ ] 老板与收银员权限隔离正确：收银员不能管理商品、库存、员工或审计日志。
- [ ] 并发抢购低库存商品时未出现负库存，成功订单数不超过库存。
- [ ] 顾客取消待确认订单只返还一次库存。
- [ ] 员工从允许状态取消订单只返还一次库存，并记录原因和审计日志。
- [ ] 未付款订单不能完成；非法或重复状态转换返回 `ORDER_STATE_CONFLICT`。
- [ ] 图片伪装、超 5 MiB 文件和非 JPEG/PNG/WebP 文件均被拒绝。
- [ ] 登录与下单限流返回 `RATE_LIMITED`，Redis 故障策略符合运行手册。
