# 智慧超市生产与体验环境设计

## 目标

为“鲁能超市李老家分店”建立一套低成本、可从微信体验版平滑过渡到正式营业的部署方案。开发阶段继续使用现有本地环境；公网阶段采用中国大陆腾讯云轻量应用服务器、已备案自有域名和受信任 HTTPS 证书。

本设计不执行云资源购买，不保存微信 AppSecret，也不把本地微信模拟登录带入公网环境。

## 已确认决策

- 采用中国大陆腾讯云轻量应用服务器。
- 购买并备案自有域名，不使用随机隧道域名或共享测试域名。
- 首期使用单台 2 核 2 GB 轻量服务器，满足小规模体验和试营业。
- 使用一个业务子域名承载管理后台、小程序 API 和商品图片。
- MySQL、Redis、Spring Boot 和 Nginx 使用现有 Docker Compose 在同一台服务器运行。
- 正式微信 AppSecret 仅保存在服务器权限为 `600` 的环境文件中。
- 本地微信登录模拟功能在体验和正式环境中保持关闭。

## 域名与网络架构

域名注册和 ICP 备案完成后，由项目负责人提供一个已解析的业务子域名。部署时将该值写入生产环境配置，不在代码中硬编码根域名。

统一入口采用以下路径：

| 路径 | 服务 |
|---|---|
| `/` | Vue 管理后台 |
| `/api/**` | Spring Boot API |
| `/files/**` | 商品图片 |
| `/actuator/health` | 受限健康检查 |

Nginx 只公开 `80` 和 `443`。HTTP 自动跳转 HTTPS；Spring Boot、MySQL 和 Redis 端口不向公网开放。

微信公众平台中，将统一 HTTPS 域名配置为：

- `request` 合法域名：小程序登录、商品、订单和个人资料接口；
- `downloadFile` 合法域名：商品图片；
- 当前版本不在小程序端上传文件，因此不配置 `uploadFile` 域名；
- 当前版本不使用 WebSocket，因此不配置 `socket` 域名。

## 环境划分

### 本地开发环境

- API：`http://localhost:8080`
- 微信模拟登录：仅本地 Docker 容器显式开启
- 用途：日常开发、自动测试、微信开发者工具联调
- 不对公网开放

### 微信体验环境

- API：统一 HTTPS 业务域名
- 微信登录：真实 `wx.login` 和微信 `code2Session`
- 微信模拟登录：关闭
- 数据库：独立体验数据，不导入真实顾客隐私数据
- 用途：体验成员真机验证、试营业验收

### 正式环境

首期与体验环境使用同一套基础设施，但正式发布前必须：

- 完成试营业验收单；
- 更换体验期间使用的临时员工密码；
- 完成数据库和图片卷备份；
- 确认微信体验版通过真机闭环；
- 使用批准的 Git 提交或版本标签重新构建。

首期不额外购买第二台服务器。订单量或可用性要求提高后，再拆分数据库、Redis 和对象存储。

## 密钥与配置边界

生产环境文件为 `deploy/.env.production`，必须满足：

- 文件权限为 `600`；
- 不提交 Git；
- `WECHAT_APP_ID` 使用已确认的小程序 AppID；
- `WECHAT_APP_SECRET` 只在服务器终端中填写；
- `JWT_SECRET` 至少使用 32 个随机字节；
- MySQL 应用密码、MySQL root 密码和 Redis 密码互不相同；
- 不设置 `WECHAT_LOCAL_MOCK_ENABLED=true`；
- `CORS_ALLOWED_ORIGINS` 只包含实际管理后台 HTTPS 来源，若后台与 API 同源则不需要额外跨域来源。

发布检查必须拒绝以下情况：

- 环境变量仍包含示例占位值；
- 体验版或正式版 API 地址仍以 `.invalid` 结尾；
- 正式环境开启微信模拟登录；
- HTTPS 证书或密钥文件缺失；
- 生产环境文件被 Git 跟踪；
- Docker Compose 渲染失败。

## 数据与账号

- 首次启动由 Flyway 自动创建数据库结构。
- 试营业商品使用现有 UTF-8 种子脚本导入一次。
- 老板账号初始化后立即修改临时密码。
- 由老板在后台创建至少一个收银员账号。
- 体验成员使用真实微信登录，后端只保存业务所需用户标识，不记录 `session_key`。
- 体验数据转正式营业前由门店负责人决定保留或清理；不得自动删除订单和审计记录。

## 发布流程

1. 购买域名和中国大陆轻量服务器。
2. 提交 ICP 备案；备案通过前继续本地开发。
3. 将业务子域名解析到服务器公网 IP。
4. 申请并安装受信任 HTTPS 证书。
5. 在服务器创建权限为 `600` 的生产环境文件。
6. 构建管理后台并启动生产 Docker Compose。
7. 验证 HTTPS、健康检查、隐藏文件防护和端口暴露范围。
8. 在微信公众平台配置合法域名。
9. 将体验版和正式版 API 地址改为统一 HTTPS 域名。
10. 运行发布前检查和完整测试。
11. 使用微信开发者工具上传代码，设置为体验版。
12. 完成真机订单闭环和试营业验收后，再提交审核与发布。

## 故障与回滚

- 应用发布失败：检出上一个已批准版本并重新构建容器。
- 数据迁移失败：停止写入，按备份恢复手册恢复数据库和图片卷；不得删除 Flyway 迁移记录。
- 微信登录失败：核对 AppID、AppSecret、合法域名和服务器时间，不切换到模拟登录规避问题。
- 证书异常：暂停体验版验证，修复证书链后重新检查；不关闭微信域名校验。
- 域名或服务器尚未准备完成：保持 `.invalid` 发布门禁，禁止上传可误用的体验版。

## 验证标准

自动验证：

- 后端完整 Maven 测试通过；
- 后台 Vitest、类型检查和生产构建通过；
- 小程序 Vitest 和 TypeScript 检查通过；
- Docker Compose 生产配置可成功渲染；
- 发布检查脚本确认没有占位值、模拟登录或被跟踪的生产密钥。

真机验证：

- 至少 5 位体验成员完成真实微信登录；
- 至少 10 笔订单完成下单、接单、备货、付款和完成闭环；
- 现金和门店微信收款码各验证至少一次；
- 商品图片在移动网络下正常加载；
- 小程序、后台、订单历史和库存流水状态一致。

## 成本与时间边界

以 2026 年 7 月腾讯云公开信息为参考，2 核 2 GB 中国大陆轻量应用服务器常规入门规格约为 45 元/月或 459 元/年，活动价以购买页面最终显示为准。域名价格由后缀和注册商决定，购买前单独确认。

腾讯云备案初审通常为 1 至 2 个工作日，管局审核最长不超过 20 个工作日。备案等待期间继续完成本地测试，不购买额外临时服务器。
