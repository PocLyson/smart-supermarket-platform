## 六、接口与权限核对结果

当前业务代码使用：

- `wx.login`：获取一次性登录凭证；
- `wx.request`：访问商品、账号、资料及订单接口；
- `wx.getStorageSync` / `wx.setStorageSync` / `wx.removeStorageSync`：保存或清除本地会话、购物车、搜索记录和待提交订单。

当前业务代码未发现：

- `wx.getUserProfile`、`wx.getUserInfo`；
- `getPhoneNumber` 开放能力；
- `wx.getLocation`、`wx.chooseLocation`；
- `wx.chooseAddress`；
- `wx.chooseImage`、`wx.chooseMedia`、相机或录音；
- 剪贴板读取；
- 通讯录、文件选择或上传。

每次提审前应重新运行接口扫描；如果新增任何隐私相关接口，必须同步修改本清单、平台指引和小程序隐私政策。
