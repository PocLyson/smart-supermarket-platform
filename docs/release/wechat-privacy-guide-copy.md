## 二、个人信息类型及用途

后台出现相应信息类型时，使用下列目的说明。

### 1. 用户填写的姓名/联系人姓名

```text
用于核对到店自取订单的取货人身份、联系取货及处理订单售后。
```

获取方式：

```text
由用户在提交到店自取订单或维护取货资料时主动填写。
```

拒绝影响：

```text
拒绝提供将无法提交需要核验取货人的到店自取订单，但不影响未登录浏览商品。
```

### 2. 用户填写的手机号码/联系方式

```text
用于订单异常通知、到店取货核验、订单联系及售后处理。
```

获取方式：

```text
由用户主动填写；当前版本不调用微信手机号快捷获取接口。
```

拒绝影响：

```text
拒绝提供将无法提交需要联系和核验的到店自取订单，但不影响未登录浏览商品。
```

### 3. 账号标识/OpenID/用户标识信息

```text
用于识别小程序账号、建立登录会话，并确保用户只能查看和管理自己的资料及订单。
```

获取方式：

```text
用户主动点击微信登录后，小程序调用 wx.login 获取一次性登录凭证，由服务端通过微信登录接口换取账号标识。
```

拒绝影响：

```text
拒绝登录将无法使用订单提交、历史订单和个人资料等账号功能，但不影响未登录浏览商品。
```

### 4. 订单信息/交易记录

```text
用于确认库存、门店备货、到店取货、订单查询、取消订单、售后、对账及交易争议处理。
```

处理内容：

```text
订单编号、商品及数量、订单金额、订单状态、取货人姓名、手机号码、创建时间、状态变更记录及取消原因。
```

### 5. 搜索记录或操作记录

如果后台提供与“搜索记录”含义相近的选项，填写：

```text
最近使用的商品搜索关键词仅保存在用户当前设备的小程序本地存储中，用于展示最近搜索并方便再次查找；用户可以在搜索页面主动清除，不用于广告画像。
```

### 6. 网络与安全日志

如果后台要求说明安全日志或设备/网络运行信息，填写：

```text
为保障接口稳定、排查故障和防范网络攻击，服务端在必要范围内记录请求时间、接口路径、响应状态、请求标识及安全日志，不用于与本服务无关的用户画像或广告营销。
```

不要主动勾选“设备信息”用于画像、营销等当前系统不存在的目的。

## 三、本地存储说明

```text
小程序在当前设备本地保存登录令牌、购物车、最近商品搜索记录及网络状态不确定时的待提交订单信息，用于保持登录状态、恢复购物车、再次搜索、确认订单结果和防止重复下单。登录令牌在会话到期、退出登录或清理本地存储后失效；购物车和搜索记录可由用户删除或清理；待提交订单在结果确认、明确失败或识别为异常数据后清除。
```

## 四、保存期限

```text
我们仅在实现处理目的所必要的最短期限内保存个人信息。登录会话保存至会话到期、退出登录或清理本地存储；取货资料在账号存续及履行订单、售后所必需期间保存；订单和交易记录按照电子商务、消费者权益保护、财税及其他适用法律要求保存，依法适用时自交易完成之日起不少于三年。超过必要期限后删除或匿名化；法律要求继续保存的，仅用于法定保存和必要安全保护。
```

## 十、当前上线阻断项

### 1. 账号注销尚未形成在线闭环

当前小程序已经提供“我的 → 注销账号”入口和服务端注销接口：

- 存在待确认、备货中或待取货订单时拒绝注销；
- 连续两次提示并确认注销后果；
- 注销后清除客户资料、可重复使用的微信账号标识和全部登录会话；
- 清除当前设备中的登录状态、购物车、最近搜索和待提交订单；
- 保留依法必须继续保存的订单及交易记录，并限制为法定保存、售后、对账、争议处理和安全保护用途；
- 用户再次微信登录时创建新账号，不恢复原账号资料。

正式提审前仍需在体验版真机验证成功注销、未完成订单阻断、全部会话失效和重新登录流程。

### 2. 正式 API 域名仍是占位地址

当前配置：

```text
开发环境：http://localhost:8080
体验环境：https://trial-api.example.invalid
正式环境：https://api.example.invalid
```

体验环境和正式环境不能使用 `.invalid` 地址提交审核。需要先完成：

1. 购买中国大陆云服务器和域名；
2. 完成 ICP 备案；
3. 配置 DNS、有效 HTTPS 证书和反向代理；
4. 将同一 HTTPS 源配置为微信公众平台 `request` 合法域名；
5. 商品图片由该域名提供时，同时配置 `downloadFile` 合法域名；
6. 把小程序 `trial`、`release` 地址替换为真实 HTTPS API 地址；
7. 真机复测微信登录、商品、购物车、下单、订单查询和注销流程。

### 3. 正式云服务商尚未确认

购买云资源后，需要使用云服务合同、账单或隐私条款中的经营主体全称更新本文件和小程序隐私政策，不要只填写“腾讯云”“阿里云”等品牌简称。
