# 智慧超市小程序视觉系统（UI UX Pro Max 红色零售方案）

## 设计方向

- 产品类型：社区智慧超市、到店自取电商。
- 视觉关键词：暖红、可信、商品优先、触控优先、扁平清晰。
- 组件库：TDesign MiniProgram `1.15.3`。
- 一级导航：首页、分类、购物车、订单；不设置 AI 助手入口。

## 核心令牌

| 用途 | 色值 |
|---|---|
| 主品牌/主按钮 | `#DC2626` |

| 页面暖白背景 | `#FFF8F6` |

| 次要文字 | `#665252` |
| 促销金 | `#A16207` |

## 尺寸规则

- 间距遵循 4/8 倍数体系，主要层级为 `8/16/24/32/48rpx`。
- 最小触控区为 `88rpx`。
- 圆角层级为 `8/16/24/32rpx`，胶囊标签使用全圆角。
- 正文不小于 `28rpx`，商品名为 `34rpx`，页面标题为 `48rpx`。
- 交互反馈使用 `150–200ms ease-out`，不使用影响布局的动画。

## 页面结构

- 首页：门店与取货方式、搜索、活动图、服务承诺、分类、双列商品、四项底部导航。
- 商品详情：商品主图、服务标签、价格与说明、固定购买栏。
- 购物车：可选商品卡、步进器、固定合计结算栏。
- 确认订单：显式字段标签、商品清单、最终金额提示、明确提交状态。
- 订单：状态与付款标签、订单金额、可点击卡片。
- 订单详情：状态头图、取货信息、商品快照、纵向状态时间线。

## 无障碍与状态

- 颜色不单独表达业务状态，状态标签同时包含文字。
- 按钮具备按压、加载、禁用状态；异步等待超过 300ms 显示反馈。
- 固定底栏预留安全区和内容内边距，避免遮挡。
- 商品图片保留固定宽高，减少加载时布局跳动。
