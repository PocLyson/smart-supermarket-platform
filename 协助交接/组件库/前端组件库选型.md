# 智慧超市前端组件库选型

> 状态：已确认
>
> 确认日期：2026-07-28
>
> 适用范围：管理后台、微信小程序、UI 设计交付

## 1. 最终选型

| 端 | 技术与组件库 | 结论 |
| --- | --- | --- |
| 管理后台 | Vue 3 + Element Plus | 唯一后台组件库 |
| 微信小程序 | 微信原生小程序 + TDesign MiniProgram | 唯一小程序组件库 |
| 小程序图标 | TDesign Icons | 默认图标来源 |

不引入 Vant Weapp、WeUI 或第二套完整组件库，避免视觉、交互和主题变量相互冲突。

## 2. 小程序使用边界

优先使用 TDesign MiniProgram 的通用基础组件：

- Button、Search、Tabs、Grid；
- Stepper、Popup、Dialog、Toast；
- Skeleton、Loading、Empty；
- Tag、Badge、TabBar。

以下组件按智慧超市业务和已确认效果图自定义：

- 首页头部与门店信息区；
- 首页轮播与运营位；
- 分类圆形入口；
- 商品卡片；
- 生鲜专区、好物榜单等推荐专区；
- 购物车商品行；
- 订单状态卡片。

自定义业务组件可以组合 TDesign 基础组件，但不得直接照搬 TDesign 零售示例项目的默认页面视觉。

## 3. 管理后台使用边界

- 表单、表格、分页、对话框、抽屉、消息提示、日期选择、上传等通用组件统一使用 Element Plus。
- 业务布局、数据概览卡片和门店运营工作台可以自定义，但应复用统一的颜色、字号、圆角与间距变量。
- 不引入第二套完整后台 UI 组件库。

## 4. 主题映射

组件库默认品牌色不直接使用，统一映射至“深绛红”视觉系统：

| 语义 | 色值 |
| --- | --- |
| 主色 / Primary | `#8E2F3F` |
| 悬停 / Hover | `#762536` |
| 按下 / Pressed | `#5E1D2B` |
| 选中浅底 / Selected Surface | `#F5E7EA` |
| 页面背景 / Page Background | `#F8F5F1` |

按钮、标签、选中态、底部导航激活态、输入框聚焦态及关键价格信息均从这套语义色派生。危险操作仍使用独立的错误色，不用主色代替。

## 5. 小程序首页固定约束

- 首页视觉以已确认的第二版深绛红效果图为准。
- 门店名称使用“鲁能超市李老家分店”。
- 底部导航固定为：首页、分类、购物车、订单。
- 不增加 AI 助手入口。
- 组件库负责基础交互一致性，页面品牌感由项目自定义组件和主题变量实现。

## 6. 执行要求

- UI 设计稿标注组件时，注明对应的 Element Plus 或 TDesign MiniProgram 组件名称。
- 前端开发新增通用组件前，先确认组件库是否已经提供。
- 如确需替换组件库或引入第二套组件库，必须先更新本决策文档并重新确认。
