## 1. 视觉方向

### 1.1 定位

深绛红用于建立本地实体超市可信、亲切、有生活温度的品牌印象，同时兼顾门店后台的中高频操作。

视觉气质：

- 稳重：深绛红比促销大红更克制，适合长期使用。
- 可信：暖白、纯白与深灰文字提供清楚稳定的信息环境。
- 亲切：保留传统零售的暖色记忆，但不显廉价或老旧。
- 清晰：品牌色只用于主要动作、当前选择和有限品牌面。
- 易学：状态色、文字、图标共同表达含义，不让用户猜测。
- 现代：使用轻边框、适度圆角和低阴影，不使用复杂装饰。

核心原则：

> 深绛红负责品牌和主要动作，暖白负责环境，白色负责内容，语义色负责业务状态。

### 1.2 基准图提炼

从基准图中提炼并保留：

- 深绛红品牌面与白色内容之间的强对比。
- 略带暖意的页面底色。
- 纯白卡片和输入容器。
- 深灰正文和清楚的价格数字。
- 少量暖金色作为生活感辅助，不与品牌主色争夺层级。
- 低阴影、细边框和适度圆角。

不直接继承：

- 参考图中的具体页面布局。
- 具体图片、商品包装、品牌和文案。
- 大面积促销式红色渐变。
- 任何 MVP 范围外的业务入口或承诺。

### 1.3 使用边界

禁止：

- 继续使用绿色作为品牌主色。
- 使用鲜红、荧光红或大面积高饱和红。
- 让错误状态与品牌主要按钮使用同一色相。
- 使用霓虹、赛博风、玻璃拟态和厚重外发光。
- 在普通卡片、表格和表单中铺设深绛红背景。
- 为所有控件使用胶囊形圆角。
- 使用多套红色渐变或无语义的红色装饰。

## 2. 品牌主色

品牌主色使用 `primary-600`，值为 `#8E2F3F`。

| Token | HEX | 建议用途 |
| --- | --- | --- |
| `primary-50` | `#FCF5F6` | 最浅品牌背景 |
| `primary-100` | `#F5E7EA` | 选中背景、浅色强调 |
| `primary-200` | `#EACBD1` | 浅边框、弱提示 |
| `primary-300` | `#D9A6B0` | 次级装饰、弱图形 |
| `primary-400` | `#C57584` | 非文字强调图形 |
| `primary-500` | `#AD4B5E` | 强调边框、链接辅助状态 |
| `primary-600` | `#8E2F3F` | 品牌主色、默认主要按钮、当前导航 |
| `primary-700` | `#762536` | Hover |
| `primary-800` | `#5E1D2B` | Pressed / Active、选中文字 |
| `primary-900` | `#451520` | 极深品牌文字，谨慎使用 |

### 2.1 有限品牌渐变

常规控件和内容容器一律使用纯色。确需表达品牌氛围的大面积品牌素材可以使用唯一的受控渐变：

```css
--gradient-brand-subtle:
  linear-gradient(135deg, #8E2F3F 0%, #A13B4A 52%, #762536 100%);
```

限制：

- 不用于普通按钮、输入框、状态标签和表格。
- 不叠加外发光或透明玻璃效果。
- 同一视图避免重复出现多个渐变面。
- 白色文字必须落在对比度足够的区域。

## 3. 主色交互状态

| 状态 | 背景 | 文字或图标 | 边框或 Focus |
| --- | --- | --- | --- |
| 默认按钮 | `#8E2F3F` | `#FFFFFF` | `#8E2F3F` |
| Hover | `#762536` | `#FFFFFF` | `#762536` |
| Pressed / Active | `#5E1D2B` | `#FFFFFF` | `#5E1D2B` |
| Focus | 保持当前背景 | 保持当前文字 | 外环 `#8E2F3F` |
| 选中态 | `#F5E7EA` | `#5E1D2B` | `#AD4B5E` |
| 浅色强调 | `#FCF5F6` | `#762536` | `#EACBD1` |
| 边框强调 | `#FFFFFF` | `#762536` | `#AD4B5E` |
| Disabled | `#E9E4E5` | `#746C6F` | `#D8CFD2` |
| 主色背景文字 | `#8E2F3F` | `#FFFFFF` | 不适用 |

推荐 Focus 样式：

```css
box-shadow:
  0 0 0 2px #FFFFFF,
  0 0 0 4px #8E2F3F;
```

Focus 不得只依靠轻微背景变化。键盘焦点必须显示清晰双层外环。

| `color-border-control` | `#877D81` | 输入框等交互控件边界 |
| `color-divider` | `#E8E1E3` | 分割线 |

- 不能仅依靠浅阴影区分控件边界。

## 5. 暖色辅助

暖金色只用于建立粮油、食品和实体零售的生活温度，不作为主要操作色，也不代替警告状态。

| Token | HEX | 用途 |
| --- | --- | --- |
| `accent-warm-50` | `#FFF8EA` | 极浅暖色背景 |
| `accent-warm-100` | `#FCECC7` | 浅色辅助背景 |
| `accent-warm-500` | `#B7791F` | 小面积图形、插图辅助 |
| `accent-warm-700` | `#7A4B0C` | 暖色背景上的文字 |

限制：

- 不用于主要按钮。
- 不与警告标签并列作为同级状态。
- 不在同一组件中同时使用深绛红、暖金和另一高饱和色。

### 9.4 数字和金额

- 金额格式统一为 `¥1,280.00`。
- 千分位和两位小数保持一致。
- 金额、库存、订单号、时间和数据列启用等宽数字：

```css
font-variant-numeric: tabular-nums;
```

- 不为数字单独下载等宽字体。
- 后台金额和数据列右对齐。
- 小程序金额的整数和小数保持稳定基线。

## 14. 可访问性

### 14.1 基础要求

- 普通正文对背景的对比度至少达到 WCAG AA `4.5:1`。
- 大字号文字和重要图标至少达到 `3:1`。
- Focus 状态必须清晰可见。
- Disabled 状态必须同时使用视觉和交互语义。
- 不能只用颜色表达状态。
- 移动端点击区域不小于 `44×44px`。
- 相邻触控目标至少间隔 8px。
- 状态标签必须保留中文文字。

- Focus 不得只改变边框颜色，必须同时显示双层外环。

- 浅色边框不承担唯一的控件识别职责。
- 状态必须由中文文字、颜色和必要图标共同表达。
- 任何后续新增颜色都必须重新进行对比度检查。
- 品牌深绛红和错误红在形状、文案与图标上也必须有明确区别。
