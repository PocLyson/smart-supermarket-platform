# 智慧超市视觉基础系统

- 视觉方向：A「青禾鲜绿」
- 状态：已废弃
- 替代方案：深绛红视觉方向（2026-07-28 经用户确认）
- 适用范围：微信原生小程序、Vue 3 + Element Plus 管理后台
- 版本：MVP 视觉基础 1.0
- 日期：2026-07-28

## 1. 视觉方向

### 1.1 定位

「青禾鲜绿」面向乡镇实体超市的真实经营与购物场景，强调：

- 清晰：信息和操作状态容易辨认。
- 可信：色彩稳重，避免廉价促销感。
- 亲切：与蔬果、食品、田野和社区生活建立自然联系。
- 易学：不同年龄用户无需学习复杂视觉规则。
- 耐用：适合门店中高频、长时间操作。
- 克制：不使用过度科技化、模板化或装饰性的视觉效果。

视觉气质定义为：

> 新鲜但不嫩，亲切但不幼态，现代但不炫技。

### 1.2 选择理由

- 深绿色天然关联蔬果、食品、健康和社区生活，符合超市场景。
- 相比互联网亮绿，`#2F7046` 更沉稳，适合后台高频操作。
- 相比科技蓝，它更亲切，也更有零售行业识别。
- 相比暖橙，它更适合长时间阅读和操作。
- 品牌绿可以同时服务小程序与管理后台，不会让两端看起来属于不同产品。

### 1.3 使用边界

避免以下表现：

- 过度科技蓝。
- 大面积高饱和红色。
- 荧光绿、霓虹色和赛博风。
- 大面积渐变、玻璃拟态和装饰性光效。
- 大量胶囊形按钮和标签。
- 厚重阴影和悬浮层级。
- 看起来像通用 SaaS 后台的蓝灰模板。
- 用品牌绿表达全部业务状态。

## 3. 主色交互状态

| 状态 | 背景 | 文字或图标 | 边框或 Focus |
| --- | --- | --- | --- |
| 默认按钮 | `#2F7046` | `#FFFFFF` | `#2F7046` |
| Hover | `#285B3A` | `#FFFFFF` | `#285B3A` |
| Pressed / Active | `#234A32` | `#FFFFFF` | `#234A32` |
| Focus | 保持当前背景 | 保持当前文字 | 外环 `#2F7046` |
| 选中态 | `#E2F0E5` | `#234A32` | `#3E8A57` |
| 浅色强调 | `#F2F8F3` | `#285B3A` | `#C3DFC9` |
| 边框强调 | `#FFFFFF` | `#285B3A` | `#3E8A57` |
| Disabled | `#E7EAE6` | `#727B74` | `#C8D0C9` |
| 主色背景文字 | `#2F7046` | `#FFFFFF` | 不适用 |

推荐 Focus 样式：

```css
box-shadow:
  0 0 0 2px #FFFFFF,
  0 0 0 4px #2F7046;
```

Focus 不得只依靠轻微背景变化，必须显示清晰外环。

## 6. 按钮配色

| 按钮 | 默认 | Hover | Pressed | 文字 | 边框 |
| --- | --- | --- | --- | --- | --- |
| 主要按钮 | `#2F7046` | `#285B3A` | `#234A32` | `#FFFFFF` | 与背景相同 |
| 次要按钮 | `#FFFFFF` | `#F0F3EF` | `#E7EAE6` | `#1F2923` | `#7C887E` |
| 危险按钮 | `#B42318` | `#912018` | `#7A1A14` | `#FFFFFF` | 与背景相同 |
| 文字按钮 | 透明 | `#F0F3EF` | `#E2F0E5` | `#285B3A` | 无 |
| 禁用按钮 | `#E7EAE6` | 不响应 | 不响应 | `#727B74` | `#C8D0C9` |

规则：

- Disabled 除颜色变化外，还必须使用禁用语义和不可点击光标。
- 危险操作不能使用品牌绿色。
- 同一区域不要并列多个主要按钮。
- 主要按钮上的文字统一使用白色。

## 8. 字体系统

### 8.1 管理后台字体栈

```css
"PingFang SC",
"Microsoft YaHei",
"Noto Sans CJK SC",
"Source Han Sans SC",
system-ui,
-apple-system,
"Segoe UI",
sans-serif
```

### 8.2 微信小程序字体栈

```css
-apple-system,
BlinkMacSystemFont,
"Helvetica Neue",
"PingFang SC",
"Microsoft YaHei",
Arial,
sans-serif
```

不远程加载 Noto Sans SC、思源黑体或其他中文字体。它们只作为设备已有字体的回退项。

### 8.3 字号 Token

| Token | 后台字号/行高 | 小程序字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| `type-caption` | 12/18px | 12/18px | 400 | 时间、极次要说明，不作长正文 |
| `type-helper` | 13/20px | 14/22px | 400 | 表单说明、辅助信息 |
| `type-body` | 14/22px | 16/24px | 400 | 默认正文 |
| `type-label` | 14/20px | 14/22px | 500 | 标签、字段名称 |
| `type-button` | 14/20px | 16/24px | 600 | 按钮文字 |
| `type-table` | 14/22px | 不适用 | 400 | 后台表格 |
| `type-card-title` | 16/24px | 17/26px | 600 | 内容标题 |
| `type-section-title` | 18/26px | 20/28px | 600 | 区块标题 |
| `type-page-title` | 24/32px | 24/34px | 600 | 页面级标题 |
| `type-money` | 20/28px | 24/30px | 700 | 金额与关键合计 |
| `type-data-emphasis` | 20/28px | 20/28px | 600 | 库存、数量、状态数据 |

字体规则：

- 后台最小正文字号为 14px。
- 12px 只能用于短标签和辅助元数据。
- 小程序默认正文为 16px，辅助正文不得低于 14px。
- 只使用 `400 / 500 / 600 / 700` 四档字重。
- 不使用过细的中文字体。

### 8.4 数字和金额

- 金额格式统一为 `¥1,280.00`。
- 千分位和两位小数保持一致。
- 金额、库存、订单号、时间和数据列启用等宽数字：

```css
font-variant-numeric: tabular-nums;
```

- 不为数字单独下载等宽字体。
- 后台金额和数据列右对齐。
- 小程序金额的整数和小数保持稳定基线。

## 9. 圆角系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-xs` | 2px | 极小状态标记、内部细节 |
| `radius-sm` | 4px | 状态标签、小型提示 |
| `radius-md` | 8px | 按钮、输入框、后台卡片 |
| `radius-lg` | 12px | 小程序卡片、下拉层、弹窗 |
| `radius-xl` | 16px | 少量重要浮层、移动端底部面板 |
| `radius-round` | 9999px | 头像、数量角标、圆形图标按钮 |

使用规则：

- 常规按钮和输入框使用 `radius-md`，不使用胶囊形。
- 后台卡片以 `radius-md` 为主。
- 小程序卡片可以使用 `radius-lg`。
- 弹窗使用 `radius-lg`。
- 较大的移动端底部面板可使用 `radius-xl`。
- 标签使用 `radius-sm`。
- 头像和真实圆形控件才使用 `radius-round`。

## 12. 可访问性

### 12.1 基础要求

- 普通正文对背景的对比度至少达到 WCAG AA `4.5:1`。
- 大字号文字和重要图标至少达到 `3:1`。
- Focus 状态必须清晰可见。
- Disabled 状态必须同时使用视觉和交互语义。
- 不能只用颜色表达状态。
- 移动端点击区域不小于 `44×44px`。
- 相邻触控目标至少间隔 8px。
- 状态标签必须保留中文文字。

### 12.3 实施注意事项

- Focus 不得只改变边框颜色，必须同时显示双层外环。
- Disabled 内容不得承担关键业务信息。
- 浅色边框不承担唯一的控件识别职责。
- 状态必须由中文文字、颜色和必要图标共同表达。
- 任何后续新增颜色都必须重新进行对比度检查。

## 13. 当前设计边界

本文件只确定视觉基础系统，不包含：

- 具体页面设计。
- 页面布局。
- 首页、商品页或后台页面结构。
- 表格布局。
- 导航结构。
- 低保真或高保真线框图。
- 组件具体组合方式。
- 管理后台或小程序代码实现。

在进入具体 UI 设计前，应以本文件作为双端统一的颜色、字体、圆角、间距、边框、阴影和可访问性基线。
