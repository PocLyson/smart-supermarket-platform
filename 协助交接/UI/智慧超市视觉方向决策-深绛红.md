# 智慧超市视觉方向决策：深绛红

- 状态：已确认
- 确认日期：2026-07-28
- 适用范围：微信小程序、管理后台及后续 UI 设计
- 替代方案：青禾鲜绿
- 视觉基准图：`智慧超市小程序首页-深绛红效果图.png`
- 完整视觉 Token：`智慧超市视觉基础系统-深绛红.md`

## 1. 决策

项目统一视觉方向由“青禾鲜绿”调整为“深绛红”。后续页面、组件、效果图和前端主题不得继续使用绿色作为品牌主色。

## 2. 核心色

| Token | HEX | 用途 |
| --- | --- | --- |
| `primary-600` | `#8E2F3F` | 品牌主色、主要按钮、当前导航 |
| `primary-700` | `#762536` | Hover |
| `primary-800` | `#5E1D2B` | Pressed / Active |
| `primary-100` | `#F5E7EA` | 选中背景、浅色强调 |
| `color-bg-page` | `#F8F5F1` | 页面背景 |
| `color-bg-surface` | `#FFFFFF` | 卡片、表格、弹窗 |
| `color-text-primary` | `#292326` | 一级文字 |
| `color-text-secondary` | `#595054` | 二级文字 |
| `color-border-default` | `#D8CFD2` | 常规边框和分隔 |

## 3. 视觉要求

- 深绛红用于品牌、主要动作和当前导航。
- 页面以暖白和白色为主，避免大面积红色造成压迫。
- 待确认使用琥珀色，备货中使用蓝色，待取货使用紫色，已完成使用青绿色。
- 取消、错误等危险状态使用偏橙的错误红，并同时配合文字或图标，避免与品牌主按钮混淆。
- 使用 4px、8px、12px 圆角等级和 4px/8px 间距节奏。
- 不使用玻璃拟态、霓虹、厚重阴影、促销式大红渐变和过多胶囊控件。

## 4. 小程序首页基准

- 保留门店抬头、搜索、主横幅、两行分类、双栏推荐专区和固定底部导航。
- 门店名称使用“鲁能超市李老家分店”。
- 底部导航为“首页、分类、购物车、订单”。
- 不提供 AI 助手入口。
- 首页不出现配送、在线支付、会员、优惠券等 MVP 外承诺。
- 商品图片使用无品牌或已获授权素材，不能照搬参考页面品牌与包装。

## 5. 后续工作

UI 设计窗口需要以本决策和基准图重新整理完整深绛红视觉 Token。管理后台与小程序窗口需要替换临时绿色主题，但不得因此改变业务逻辑。
